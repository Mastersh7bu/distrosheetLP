What happens when you send a sheet

Your sheets stay in Google. DistroSheet does not keep a copy of your spreadsheet. When you send a file, we tell Google to copy it and share it with that person’s email. Google holds the file.

When you push an update, we tell Google which cells to change. Those values pass through DistroSheet only for that request. We do not save them.

We do store the details needed to send again: your email, each recipient’s email, the Google file IDs, the cells and tabs you marked to leave alone, and a Google sign-in token so we can act as you. If you add an Apps Script ID, we store that ID too. The script itself is not saved.
