Features

The same controls as the extension.

Open a Google Sheet and sign in. Deliver the file, then let DistroSheet handle updates when you improve it.

Google sign-in

Continue with Google so DistroSheet can deliver the file and write updates through Sheets.

The open sheet is the source

The spreadsheet you have open is the one DistroSheet delivers. Updates start from that file.

Send the file

Enter a recipient email. DistroSheet sends them the file and remembers them for later updates.

Deliver updates

When the sheet changes, DistroSheet updates everyone who already has the file. A new recipient gets it with Send file.

Protected cells

List A1 ranges where recipients enter their own data, like B2:B10, D4. Updates leave those cells as they are.

Tabs left untouched

Name whole tabs to leave alone when you update — exact names, like _engine or Lookup. Those stay as the recipient left them.
