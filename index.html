Values

One source sheet. A copy for every client.

DistroSheet keeps the work in Google Sheets. You stay on the file you already trust, and each recipient gets a spreadsheet of their own.

01

Their file, not a shared mess

Send copy clones the spreadsheet in Drive and shares it with one email. That person edits their copy. They never type over yours.

02

What they type stays put

Mark the cells clients fill in, and name any tabs that should be left alone. A publish skips those, and writes everything else.

03

One update, every copy

Change the master sheet once. Publish pushes values and formatting to the people who already have a copy — no files to resend.

Features

The same controls as the extension.

Open a Google Sheet, sign in, and the file links itself. From there you send copies and publish updates.

Google sign-in

Continue with Google so DistroSheet can clone the file in Drive and write updates back through Sheets.

The open sheet is the source

The spreadsheet in the current tab becomes your Sheets file. Later publishes start from that file.

Send copy

Enter a client email. DistroSheet clones the spreadsheet, shares it with them, and remembers them for the next publish.

Publish update

Push the master into every copy you’ve already sent. Someone new still needs Send copy — publish is for people already on the list.

Protected cells

List A1 ranges where recipients enter their own data, like B2:B10, D4. Send copy still includes them. Publish does not write there.

Tabs left untouched

Name whole tabs to skip on publish — exact names, like _engine or Lookup. Those sheets stay as the client left them.
